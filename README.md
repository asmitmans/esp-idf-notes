# ESP-IDF Notes

Technical notes and minimal examples for embedded development with
Espressif ESP32 and ESP-IDF.

## Objectives

- Understand ESP32 hardware and ESP-IDF fundamentals.
- Learn project structure, configuration and build tools.
- Develop minimal examples using GPIO, peripherals and FreeRTOS.
- Explore Wi-Fi connectivity, networking and persistent storage.
- Apply basic testing, debugging and continuous integration practices.

## Hardware

- SoC: ESP32
- Module: ESP32-WROOM-32E-N4
- Development board: ESP32 DevKit (38 pins)

## Development environment

- OS: Ubuntu Linux
- Framework: ESP-IDF
- Language: C
- Editor: Visual Studio Code
- Build and flashing tools: ESP-IDF CLI (`idf.py`)
